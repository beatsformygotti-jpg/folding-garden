# Складной сад · Folding Garden

[Играть / Play](https://beatsformygotti-jpg.github.io/folding-garden/) · [English](https://beatsformygotti-jpg.github.io/folding-garden/?lang=en)

Головоломка про зеркальные сгибы бумаги в 3D. Коснитесь линии сгиба или потяните за кружок. Совпавшие половинки пополняют гербарий. Все 50 уровней доступны из меню. Выбор языка и прогресс хранятся в браузере.

A 3D paper-folding puzzle. Tap a fold line or drag its circle. Matching flower halves go into the herbarium. All 50 levels are available from the menu. Your language and progress are saved in your browser.

## Локальный запуск / Run locally

Откройте `index.html` в браузере. Для запуска через HTTP из этой папки выполните `python3 -m http.server 8765` и откройте `http://localhost:8765`.

Open `index.html` in a browser. To use HTTP, run `python3 -m http.server 8765` from this folder and open `http://localhost:8765`.

The bundled fonts and Three.js are accompanied by their licenses in `assets/`.
